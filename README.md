# 🚀 RUN LOCALLY

Clone the repository:

```bash
git clone https://github.com/shayanonetwo-12/My-Portfolio.git
```

Enter the project:

```bash
cd My-Portfolio
```

Install dependencies:

```bash
npm install
```

Launch development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

Run code quality checks:

```bash
npm run lint
```

Run TypeScript checks:

```bash
npm run typecheck
```
